# Painel Bancário Abstrato

Sistema bancário visual e estático para a atividade de IHC. Roda completamente no navegador, sem backend e sem necessidade de conexão após instalar as dependências.

## Executar

```bash
npm install
npm run dev
```

Use `npm run build` para gerar a versão de produção.

## Funções

O painel apresenta saldo, reserva, gráfico e histórico de movimentos. Os cinco botões geométricos abaixo do cartão acionam as funções bancárias: entrada de saldo, saída de saldo, transferência à reserva, resgate da reserva e mostrar/ocultar histórico. O botão circular no trilho lateral restaura os valores iniciais.
